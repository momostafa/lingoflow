📚 LingoFlow System Documentation & Help

Learn how to maximize your linguistic practice, configure local AI engines, and manage static audio assets.

🚀 Core Application Features

🎛️ Unified Practice Matrix

Review conversational expressions across multiple languages simultaneously. Filter dynamically by categories (e.g., Bargaining, Transit, Social) to narrow down focus paths.

🔊 Self-Compiling Audio Tracks

The system scans local hard drive buffers on demand. If an audio file disappears or hasn't been generated yet, a native macOS TTS sub-routine instantly compiles it.

⚡ Interactive AI Copilot

Launches an instantaneous side drawer to harvest context-aware tactical tips, word-for-word grammatical decompositions, or localized bazaar negotiation lines.

📥 Dynamic CSV Spreadsheet Import

Bulk load vocabulary charts instantly. The system sanitizes text blocks, flags missing target cells, and formats SQLite indexing anchors automatically.

🤖 AI Engine Interfacing (llama.cpp vs. LM Studio)

LingoFlow utilizes a refactored unified AsyncOpenAI engine pipeline. You can dynamically switch endpoints via your Settings panel row:

Target Platform Default Base URL Recommended Server Flags
llama-server http://127.0.0.1:8080 -c 4096 -np 1 (Enforces single-lane max performance)
LM Studio http://127.0.0.1:1234 Ensure Cross-Origin Resource Sharing (CORS) is explicitly checked.
⚠️ Troubleshooting Tip: If your side modal drawer displays indefinitely or fails to fetch, launch your browser dev console. Ensure the host endpoint is up, running, and successfully answering requests on the exact port configured in your app panel.

❓ Frequently Asked Questions

How do I trigger full audio rebuilds?

Navigate to your dashboard footer or toolbar parameters and tap "Regenerate Missing Assets". This will safely cross-verify every database phrase against local disk memory storage paths.

Can I modify the AI's persona tone guidelines?

Yes! In your system setup settings, shift between the Bazaar Negotiator profile (for sharp counter-offers) and the Linguistic Tutor matrix (for detailed semantic grammar tear-downs).
